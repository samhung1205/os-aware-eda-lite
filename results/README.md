# results/: what is tracked, what each file is, and how far it can be trusted

Nothing in this directory is a verified ROS 2 measurement yet. `python3 scripts/check_runtime_provenance.py`
reports `BLOCKED` until real raw runs are committed (exit 0 = VERIFIED, 1 = BLOCKED, 2 = BROKEN).

## Tracking policy

| Path | Content | Git | Rule |
|---|---|---|---|
| `raw/ros2/<run_id>.csv` | detector rows of one real ROS 2 run | tracked | never edited, never appended; the hash chain starts here |
| `raw/ros2/<run_id>.publisher.csv` | one row per published frame | tracked | needed for complete drop accounting |
| `raw/ros2/<run_id>.meta.json` | run conditions (`measurement_class`, limits, versions, RMW, QoS) | tracked | written before launch by `src.ros2_runtime.run_metadata` |
| `raw/ros2/*.failed` | runs that ended early / failed limit checks | ignored | kept locally for debugging, never analysed |
| `csv/*.csv` | derived tables (simulation sweeps, summaries, ROS 2 summary) | tracked | each is regenerated by a command in the README |
| `csv/*.provenance.json` | simulation sidecars: SHA-256 of output, config, model profile, OS profile file + status | tracked with its CSV | a CSV without its sidecar is not reportable |
| `csv/ros2_runtime_summary.manifest.json` | SHA-256 of the summary and every raw input | tracked with the summary | written by `analyze_runtime` |
| `figures/**/*.svg` | charts produced by scripts | tracked | regenerate, never hand-edit |

Commit raw runs, summary + manifest, `experiments/eda_lite/runtime_os_profiles.json`, simulation CSVs
and sidecars **together**; a missing link turns the provenance check back to `BLOCKED`.
